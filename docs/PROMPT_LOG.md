# Prompt log index

Each entry is a concise **AI-written interpretation**, not a verbatim user prompt or proof of human prompt authorship. Preserve intent; never invent requirements, checks or outcomes. English summaries may come from Bangla or English requests. Original prompts remain in their source conversations when available; this index is not a full transcript.

Log only explicit implementation, commit or push commands and the actual work/checks/delivery evidence associated with them. Never record questions, explanations, brainstorming, examples, normal conversation or discussion-only clarifications, even as summaries. Discussion must not trigger log/task/view writes. Classify intent, not punctuation: “Can you implement X?” is an action; “How would X work?” is discussion. Mixed messages contribute only their action instruction. Use --kind implementation, commit or push; do not infer commands from discussion. Local work remains not pushed until actual delivery evidence is available. Members use separate batches, at most 50 entries each. Read the index/current relevant batch, not every historical log. `unassigned` means the requesting member was not confirmed. Recorded UTC is the logging time; a backfill does not invent the original timestamp.

See [workflow instructions](WORKFLOW.md) and [AI-use disclosure](AI_USE.md). Add entries with `python3 scripts/workflow.py log`; never include credentials/private data.
