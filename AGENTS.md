# Soil to Stars repository guidance

- Read the README and only the source files relevant to the task. Keep the mounted Next.js app in `prototype/`, with Python acquisition, computation and SQLite service code in `src/`.
- Preserve source IDs, original units, data receipts, licenses, crop and regional scope, and the distinction between historical observations and advice. Keep unavailable evidence explicit. Never substitute a test fixture for real data or invent scores, thresholds, yields, or rankings.

- Use `make check` and `make build` for affected changes. Credit implementation assistance and human contributions in `docs/AI_USE.md`. Follow the user's current authorization for delivery.
