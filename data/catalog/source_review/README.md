# Source-calendar semantics review

Task `CROP-SOURCE-SEMANTICS`, Maruf, local branch `maruf/crop-evidence-prep`. This is assistant preparation for independent review. It does not approve source science, repair calendar labels, define executable rules or alter the shared API.

## Confirmed local finding

All **13 collected Lentil regions** were compared using physical source-column order, without prioritizing a region or substituting regional weather. Four calendars share a printed month-label gap:

| BAMIS region | Original source PDF, page 1 | Observed labels |
| --- | --- | --- |
| Dhaka | `BAMIS_All_Crops/Lentil/Dhaka/8731.pdf` | December → February at week-label reset 52 → 1; February covers 1–4, March 5–6 |
| Faridpur | `BAMIS_All_Crops/Lentil/Faridpur/8729.pdf` | Same printed sequence |
| Mymensingh | `BAMIS_All_Crops/Lentil/Mymensingh/8726.pdf` | Same printed sequence |
| Rajshahi | `BAMIS_All_Crops/Lentil/Rajshahi/8725.pdf` | Same printed sequence |

Each original local PDF's SHA-256 matched the frozen extraction before its header was rendered and visually inspected. The missing January label is visible in the original sources. This establishes a printed gap; it does **not** establish which label is wrong, an ISO-week convention or a corrected date. All source months, weeks, durations and weather remain unchanged. The nine other collected Lentil regions are comparison evidence, not replacements for these four. The [official Lentil listing](https://www.bamis.gov.bd/en/calendar/1/58/) also lists 13 regions; absent Rangamati coverage means unavailable evidence, not unsuitable land.

See [the full Lentil comparison](lentil_region_comparison.json) for every original month group, week label and source column. Exact inspected-source records are appended to `../evidence_inputs/source_reviews.json` and rebuilt into the normalized package. Existing legacy candidates are preserved unchanged.

## Definition leads across all sources

The offline audit covers **all 318 frozen extracted documents across 14 regions**, with no crop or region cap. It found **320 table rows** containing weather-metric and explicit temporal wording. These remain raw review leads:

- 175 rows are under detected pest/disease headings.
- 87 are under weather-warning headings.
- 56 are under crop-requirement/preference headings.
- Two have no recognized section heading.

Section classification uses English heading patterns, not human scientific interpretation. Every row retains source PDF, page, table, row, original cell IDs and raw cell values. Every lead explicitly has `executable=false` and `usable_as_normal_definition=false`. A weekly rainfall phrase in a pest warning cannot define the accumulation convention of the separate normal-weather table. See [interval wording leads](interval_wording_leads.json).

The English search patterns found no explicit reference-year range or week-convention leads in the extracted page text. **This is a search result, not proof that the originals contain no definitions.** Bengali/OCR text, images, missed extraction and separate methodology publications remain possible gaps. No climate period, station weighting, week/date mapping, daily statistic or sunshine accumulation interval has been assigned. See [per-document search results](document_definition_leads.json) and [summary limitations](summary.json).

## Official context checked online

[DAE's weather-sensitivity presentation, PDF page 25](https://www.bamis.gov.bd/res/attachment/2020/02/16/13310.pdf) describes normal weather, crop requirements and pest/disease conditions as separate calendar information roles. [DAE's agrometeorology presentation, PDF page 11](https://www.bamis.gov.bd/res/attachment/2020/02/16/13328.pdf) also discusses calendar warning and weather components. These support keeping the evidence roles separate; they do not settle this collection's reference years or calculation conventions.

The official Rajshahi Lentil page exposes a direct PDF link, recorded in [web checks](web_source_checks.json). Online PDF byte retrieval failed, so no equality with the local copy is claimed. Training-PDF text was accessible but screenshots failed. No original online PDFs or images were copied into the repository; reuse rights, publication versions and raw-download hashes remain unknown. URL path dates are not treated as publication dates.

## Reproduce

No network or third-party package is needed for the corpus audit. From the repository root:

```text
python -X utf8 scripts/audit_crop_source_semantics.py
python -X utf8 scripts/audit_crop_source_semantics.py --check
```

The audit emits UTF-8/LF JSON and a [receipt](receipt.json) pinning its source snapshot, script and generated JSON. `--check` compares the five generated outputs byte-for-byte. The separate human-readable report and web-check notes document the assistant's source investigation; they are not generated by the text-pattern audit or evidence of independent human review.
